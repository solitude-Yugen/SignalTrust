SignalTrust 💓

Quality-Aware Heart Rate Monitoring from Wrist PPG — Knowing when to trust the wearable.
"We don't trust the wearable. We measure when to, and prove it."

Track Biomedical AI · Image & Signal Analysis

The Problem
Wearables lie — silently.
PPG HR is reported even when the signal is useless
😤

What happens today

  • User moves wrist during workout
  • PPG signal corrupted by motion
  • Estimator outputs a number anyway
  • Reported HR: 142 bpm. Actual: 87 bpm. ❌
  • No flag, no warning, no abstention
Ungated PPG MAE on WESAD: 8.76 bpm — nearly clinically meaningless
✅

What SignalTrust does

  • Scores each 8 s window of PPG
  • Reports HR only when quality ≥ threshold
  • Abstains (shows "—") when uncertain
  • Coverage + accuracy are both shown
  • The trade-off is made explicit, not hidden
Gated MAE at 50% coverage: 2.65 bpm  →  70% reduction
The Approach
A calibrated quality gate on every window
LOSO · HistGradientBoosting · Isotonic calibration · 8 features
📦
Input
Raw wrist BVP (64 Hz) + ACC. 8 s windows, 2 s stride.
→
🔬
Features (8)
SNR, skew, kurt, IBI-CV, template corr, acc_std, acc_range, BVP std
→
🧠
Quality Model
HistGBT + isotonic calibration. LOSO. Outputs p(usable) ∈ [0,1].
→
⚖️
Gate @ 0.70
Threshold chosen on held-out subjects to cap false-accept ≤ 5%.
→
💓
Output
HR reported ✓ if gate passes. Withheld ✕ if rejected.
📐 Label: usable = |HR_ppg − HR_ecg| ≤ 5 bpm — non-circular, ECG-only reference
🔒 No leakage: LOSO — each subject is fully held out once
📏 Metric: MAE vs. coverage (not just accuracy)

⚠️ Failure mode — PPG-only periodic motion

When a periodic burst at pulse frequency is injected into PPG only (accelerometer calm), the SNR feature self-validates against the estimator's own Hz estimate. Both the model and SNR gate fail.
PPG-only motion sev 4:
Bad rate: 88.5%  ·  False-accept: 67.8%  ·  Gated MAE: 37.1 bpm
Fix (roadmap): PPG–ACC spectral coherence feature
We report this honestly — not hidden. The accelerometer gate catches coupled motion perfectly; the model catches everything else.

Limitations & Roadmap
Honest evaluation — and what's next
We report limitations explicitly — the rubric asks for it, and it's the right thing to do

⚠️ Current Limitations

1
Single dataset: WESAD, 15 subjects, one wrist device, lab conditions. Cross-dataset BIDMC looks good, but generalization is unproven at scale.
2
PPG-only motion failure: strong periodic motion in the pulse band fools the SNR gate and the model. Only the accelerometer catches coupled motion.
3
Non-causal filter: filtfilt used offline. Dashboard shows a replay of pre-computed scores. Real-time deployment needs a causal filter.
4
Label noise: ~15% of quiet-wrist windows still disagree with ECG; cause not proven.
5
Synthetic stress test: artifacts injected on clean windows — not a real-world prevalence estimate.

🚀 Roadmap

1
PPG–ACC spectral coherence feature: closes the PPG-only motion gap — a frequency-domain check that doesn't depend on the estimated HR.
2
Causal on-device inference: replace filtfilt with causal IIR; export model to TFLite or ONNX for wearable deployment.
3
Artifact-type classifier: separate motion / dropout / saturation / wander to give targeted feedback to the user.
4
Larger cohorts: PPG-DaLiA, consumer wearable exports, clinical populations. Diverse devices and demographics.
5
PPG/ECG fusion: for clinical-grade accuracy when ECG is available (e.g., smartwatch with ECG lead).
